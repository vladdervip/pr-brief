# PR Brief

Простой инструмент для продакта: вставил ссылку на GitHub PR — получил короткий бриф на русском.

## Зачем

Дифф читать долго. Нужно быстро понять: что меняется для пользователя, где риск, можно ли смотреть на мерж.

## Что делает

1. Берёт PR по URL или `owner/repo#123`
2. Тянет метаданные и список файлов через GitHub API
3. Собирает бриф:
   - Что меняется для пользователя
   - Риск / что может сломаться
   - Объём изменений
   - Вердикт: можно смотреть / осторожно / блокеры

Если есть `OPENAI_API_KEY` — формулировки чуть умнее. Без ключа работает шаблон по данным PR (тоже полезно).

## Запуск

```bash
cp .env.example .env
# впиши GITHUB_TOKEN
npm install
npm run dev
```

Открой http://localhost:3000

## Env

| Переменная | Нужна? | Зачем |
|---|---|---|
| `GITHUB_TOKEN` | да | читать PR |
| `OPENAI_API_KEY` | нет | более живой текст брифа |
| `PORT` | нет | порт сервера, по умолчанию 3000 |
